# Versión publicable (GitHub Pages)

`index.html` es la misma aplicación que `orbital-lab/`, pero en un solo archivo y
sin paso de build: Phaser 3 se sirve desde `phaser.min.js`, aquí al lado.

Para publicarla: **Settings → Pages → Source: Deploy from a branch → `master` / `/docs`**.
Queda en https://miguellop2013.github.io/bootcamp/

Para editar el código con recarga en caliente, usar el proyecto Vite de `orbital-lab/`
y volcar los cambios aquí.
